# Theme Sources by Editor

## Zed
- Schema: https://zed.dev/schema/themes/v0.2.0.json
- Reference themes: https://github.com/zed-industries/zed/tree/main/assets/themes
- User themes dir (macOS/Linux): `~/.config/zed/themes/`
- User themes dir (Windows): `%APPDATA%\Zed\themes\`
- Webhook note: GitHub raw URLs often 404 due to URL encoding; use `?plain=1` on blob URLs or clone the repo locally to inspect themes.

## VS Code
- Schema: contributes.themes in package.json
- Reference: https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults/themes
- User themes dir: `~/.vscode/extensions/` (per-user)

## Helix
- Format: TOML
- Reference: https://github.com/helix-editor/helix/tree/master/runtime/themes
- User themes dir: `~/.config/helix/themes/`

## Kitty
- Format: conf/ini-style
- Reference: https://github.com/kovidgoyal/kitty-themes
- User themes dir: `~/.config/kitty/themes/`

## Ghostty
- Format: gtheme or conf
- Reference: https://ghostty.org/docs/config
- User themes dir: `~/.config/ghostty/themes/`
