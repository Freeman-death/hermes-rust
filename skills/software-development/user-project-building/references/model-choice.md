# Model choice

Day-to-day = local. Upchain to cloud when the task needs it (heavy compute, proprietary APIs, gemma4-level reasoning).

| Need | Model |
|---|---|
| File / terminal / code exploration | local Qwen |
| Broad building or heavy lifting | cloud |
| Hackathon build | cloud only, mainly gemma4 |

Do not claim a model is available from memory — check config, credit, and runtime first.
